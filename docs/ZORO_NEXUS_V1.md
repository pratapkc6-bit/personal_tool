# Zoro Nexus v1.0

Zoro Nexus is the major product and visual redesign of Pratap Personal Secretary.

## What changed

### Personal operating-system shell
Desktop now uses a persistent command rail with Command Center, Zoro AI, Missions, Timeline, Intelligence, Search, Activity, Connections and Preferences.

### Global command layer
Press **Ctrl+K** or **Cmd+K** from anywhere to open the global command palette. It provides direct access to the Assistant, task capture, calendar, Gmail scanning, search and settings.

### Futuristic design system
The app now uses a dark spatial canvas, cyan/blue/violet intelligence accents, glass surfaces, a live system-status indicator, a responsive mobile dock and an animated Zoro orb.

### Core workspaces redesigned
- Assistant: presented as the AI command layer.
- Inbox: presented as an intelligence grid with clearer signal/action hierarchy.
- Calendar: presented as a temporal map.
- Tasks: presented as mission control.
- Home: existing Command Center logic is preserved but visually transformed by the Nexus theme.

### Existing behaviour preserved
This release does not replace Google OAuth, Gmail scanning, Calendar CRUD, MYOB roster reconciliation, task management, wake-word voice mode, assistant preferences, confirmation tokens, on-device WebLLM, saved focus plans or local secretary intelligence.

## Safety
Write actions remain confirmation-gated. The redesign changes product experience and navigation, not the safety model.
